## Why it exists

A short note can preserve the current purpose or unresolved question of a thread without adding a
new chat message. Thread annotations are separate from preview annotations and diff comments.

## Before you start

Enable **Settings → General → Legacy features → Sidebar (legacy)**. See
[Legacy sidebar conveniences](/features/legacy-sidebar/) if you have not used that sidebar before.

## Add and use an annotation

1. In the legacy sidebar, open the thread's context menu and choose **Annotate thread…**.
2. Write one Markdown note. Headings, lists, task lists, and tags are supported.
3. Save it. The thread timestamp gains a dotted yellow underline, and the open thread shows a
   pale-yellow card above the composer.
4. Hover the underlined timestamp to read or edit the note without opening the thread.

You can dismiss the composer card for the current visit without deleting or resolving the note.

## Resolve or reopen it

Resolve the annotation when the note no longer needs attention. It disappears from the sidebar
and composer but remains attached to its yellow conversation-minimap marker.

Select that marker to read, edit, or reopen the annotation. Editing, resolving, or reopening moves
the marker to the newest message in the thread.

## Limits

- A thread has one annotation at a time.
- Dismissing the composer card is temporary; resolving changes the annotation's state.
